# Youssef Ahmed – Personal Portfolio Website (v2)

A clean, responsive personal portfolio website built with pure HTML and CSS — no frameworks or JavaScript libraries.

## 📄 Pages & Sections

The site is a single-page layout (`index.html`) with the following sections:

| Section | Description |
|---|---|
| **Header / Nav** | Fixed top navigation bar with links to each section |
| **Hero** | Intro banner with name, tagline, and a call-to-action button |
| **About** | Short bio with a placeholder image |
| **Skills** | Three skill cards: Frontend Development, UI Layout & Structure, Accessibility |
| **Projects** | Showcases the portfolio site itself with a "View Code" link |
| **Testimonials** | Two client quote cards |
| **Contact** | Email & phone info plus a contact form (name, email, message) |
| **Footer** | Copyright notice and links to GitHub and LinkedIn profiles |

## 🛠️ Tech Stack

- **HTML5** – semantic elements (`header`, `nav`, `main`, `section`, `footer`, `form`)
- **CSS3** – custom properties (CSS variables), Flexbox, smooth scrolling, transitions, and a media query for mobile responsiveness (≤ 768 px)

## 📁 Project Structure

```
html-portfolio-v2/
├── index.html      # Main page
├── style.css       # All styles
├── images/         # SVG icons (GitHub, LinkedIn)
└── README.md
```

## 🎨 Design Highlights

- Light color scheme with a white/light-gray background and `#2563EB` (blue) accent
- Fixed header that stays on top while scrolling
- Smooth scroll behavior between sections
- Hover effects on buttons, skill cards, project cards, and footer social icons
- Fully responsive layout that stacks columns on small screens
